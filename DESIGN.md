# Documentation A — precise whitespace

Read mode. This is the selected A direction from the documentation prototypes.
Use a white canvas, quiet gray surfaces and a single cobalt action color (`#2358ce`).
Pair dark backgrounds (`#101115`, `#181b21`) with readable gray text and a lighter blue (`#90afff`).
Use the transparent V mark without a decorative hero illustration.

The 64px header keeps native search, language and theme controls. A 246px sidebar provides persistent navigation.
The homepage starts with one application-integration action, three ordered steps, language SDK links and task guides.
Articles retain native sidebar, breadcrumbs, in-page contents, anchors, copy buttons and pagination.

Body text is 15px with generous line height; mobile is 14px. Keep prose around 70 characters per line.
Prefer fine borders and open lists to layered cards. Code and tables scroll within their containers.
The content collapses to one column on mobile; Docusaurus owns navigation and focus behavior.
Respect reduced motion, show visible keyboard focus and retain full EN/zh-CN support.
