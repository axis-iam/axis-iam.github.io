# Axis Vertex overview

Axis Vertex is an Application Identity Platform. An **Application** owns the user directory, ApplicationClients,
roles, permissions, B2B Organizations, identity-provider connections, SCIM connections, and delivery configuration
used by one product. Access tokens are issued for a concrete ApplicationClient and resource audience.

## Ownership model

| Resource | Boundary | Purpose |
| --- | --- | --- |
| Workspace | Developer console | Owns Applications and provides configuration defaults. |
| Application | Product identity boundary | Owns users, clients, authorization, SSO, SCIM, and Organizations. |
| ApplicationClient | OAuth client | Defines client type, redirect URIs, origins, grants, and secret behavior. |
| Organization | Application-owned B2B group | Groups App Users and can participate in authorization context. |

An Organization is not a tenant-wide configuration layer. SSO, SCIM, branding, authentication policy, and delivery
configuration remain Application-level contracts.
