# 预构建认证 Dialog

React SDK 的预构建 Dialog 将 Vertex 认证状态封装在弹窗中。应用控制弹窗何时打开以及认证成功后的导航；组件控制当前认证步骤、校验展示、身份提供商启动、回调延续与焦点约束。

需要在应用当前页面提供认证入口、又不想重建全部状态时使用 Dialog。`mode="redirect"` 启动 Hosted 认证，`mode="embedded"` 在弹窗中呈现受控认证事务；两者最终都通过 Authorization Code + S256 PKCE 完成。内嵌模式不再使用退役的 Direct 登录或 Direct 刷新接口。

只展示当前登录/注册意图允许的方式，保留必需的 MFA 与第三方回调延续步骤。关闭弹窗不代表服务端操作已经取消；取消或完成结果不确定时，应保留 SDK 的明确恢复提示，而不是显示成功。

应用仍须提供 SPA 公开客户端、精确重定向 URI、登出 URI 与允许 origin，并提供无障碍触发器，在 Dialog 关闭后恢复焦点。
