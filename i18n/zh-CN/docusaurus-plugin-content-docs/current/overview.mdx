# Axis Vertex 概览

Axis Vertex 是应用身份平台。一个 **Application** 拥有单个产品所使用的用户目录、ApplicationClient、角色、权限、B2B Organization、身份提供商连接、SCIM 连接与交付配置。访问令牌面向明确的 ApplicationClient 和资源 audience 签发。

## 所有权模型

| 资源 | 边界 | 用途 |
| --- | --- | --- |
| Workspace | 开发者控制台 | 拥有 Application 并提供配置默认值。 |
| Application | 产品身份边界 | 拥有用户、客户端、授权、SSO、SCIM 与 Organization。 |
| ApplicationClient | OAuth 客户端 | 定义客户端类型、重定向 URI、origin、grant 与密钥行为。 |
| Organization | Application 所属的 B2B 分组 | 对 App User 分组，并可参与授权上下文。 |

Organization 不是租户级配置层。SSO、SCIM、品牌、认证策略与交付配置仍属于 Application 级契约。
