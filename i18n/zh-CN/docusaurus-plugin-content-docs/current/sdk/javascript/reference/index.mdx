# JavaScript API 参考

## 当前源码接入说明

以下指南对应当前尚未发布的 SDK 源码候选版：

| 功能 | 公开入口 | 指南 |
| --- | --- | --- |
| 认证 | `useAuthFlow`、`SignIn`、`SignUp`、`AuthDialog` | [认证模式](../../../authentication/)、[自定义表单](../../../authentication/custom/) |
| 账号管理 | `AccountCenter`、`AccountSecurityPanel`、`AccountSecurityDialog`、`useAccountSecurity`、`useIdentityOperations` | [账号安全](../../../authentication/account-security/) |
| 邀请 | `OrganizationInvitationAccept`、`useInvitationJourney`、`InvitationJourneyClient` | [邀请旅程](../../../organizations/) |

[源码接入索引](https://github.com/axis-iam/vertex-sdk-js/blob/develop/docs/current-integration.md)

## 历史 preview 参考

现有生成的 TypeDoc 页面对应 `static/source-revisions.json` 记录的旧源码版本，
**尚未为当前候选版重新生成**。其中可能包含已经退役的 `useOrganizationInvitation`、
邀请 `token` 属性和 `onLoginRequired`，新接入不能沿用这些邀请合同，应以本页列出的当前指南为准。

本次手写文档更新没有重新生成 API 参考，也没有修改旧产物的版本来源记录或发布任何包。
历史生成页面可从英文版参考入口查看。
